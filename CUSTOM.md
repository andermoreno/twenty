# Customizações do fork

Este arquivo existe apenas no fork (branch `twenty-custom`) e não no upstream.
Serve como marcador para validar o fluxo de atualização a partir do Twenty oficial.

## Convenções deste fork

- `main` espelha o upstream (`twentyhq/twenty`), nunca recebe edição manual.
- `twenty-custom` concentra as customizações estáveis.
- Preferir arquivos/módulos novos e o `twenty-sdk` a editar o core.
